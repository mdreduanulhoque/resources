# Resources

The best resources an IT person needs day to day: AI tools, learning resources, books, newsletters, and tutorials. One new resource is added every day.

## Best AI Tools

- **ChatGPT by OpenAI**: https://chat.openai.com. AI assistant for coding help, debugging, writing, brainstorming, and learning new topics. Free plan available.
- **Claude by Anthropic**: https://claude.ai. AI assistant for coding help, writing, and working through hard problems. Free plan available.

## Programming & Learning Resources

- **Python**: https://www.learnpython.org/. Free interactive Python tutorial for beginners.
- **freeCodeCamp**: https://www.freecodecamp.org/. Free coding lessons and practice projects for people starting out with web development.
- **MDN Web Docs**: https://developer.mozilla.org/. Free reference and learning guides for HTML, CSS, JavaScript, and web APIs, kept by Mozilla and used by web developers every day.

## Best Books for Learning

- **Eloquent JavaScript**: https://eloquentjavascript.net/. Free online book by Marijn Haverbeke that teaches JavaScript from the basics to advanced topics with exercises and projects.
- **Automate the Boring Stuff with Python**: https://automatetheboringstuff.com/. Free online book by Al Sweigart that teaches Python by writing small programs to handle everyday tasks like renaming files, working with spreadsheets, and sending emails.

## Best Newsletters

- **TLDR**: https://tldr.tech. Free daily email with short summaries of the most interesting stories in tech, startups, and programming, so you can stay current in a few minutes each morning.
- **Morning Brew**: https://www.morningbrew.com. Free daily email that covers business, tech, and finance news in a short and easy read, good for anyone who wants to stay updated without reading long articles.

## Best Tutorials

- **The Odin Project**: https://www.theodinproject.com/. Free full stack web development curriculum with guided lessons and projects for people learning to build websites from scratch.
